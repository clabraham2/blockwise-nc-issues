# Blockwise NC — issues and feedback

This is the place to report bugs and request features for **Blockwise NC**, the VS Code extension for editing NC (G-code) programs with backplot, cycle time and file compare.

- [Report a bug](https://github.com/clabraham2/blockwise-nc-issues/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/clabraham2/blockwise-nc-issues/issues/new?template=feature_request.yml)
- [Browse open issues](https://github.com/clabraham2/blockwise-nc-issues/issues)

You can also file a report from inside VS Code: run **Help: Report Issue…** from the Command Palette and choose Blockwise NC. It fills in your VS Code, OS and extension versions.

## Before you file

- Search the open issues first; add a 👍 or a comment to one that matches.
- This repository is public. Do not attach programs, setup files or drawings you are not free to share. A few lines that reproduce the problem are usually enough.

## What helps most in a bug report

- The extension version (Extensions view → Blockwise NC) and whether you are on desktop VS Code or vscode.dev.
- The NC file type shown in the status bar, and the machine if one is chosen.
- The shortest program that shows the problem, pasted as text.
- What you expected and what happened instead; a screenshot for anything in the backplot.

This repository holds issues only. The extension's source code is not published here.
